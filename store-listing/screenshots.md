TapTap 商店页需要一组截图与图标。本目录已提供 **应用图标**，截图为「待补」——请在手机/模拟器上运行游戏后按下方清单截取。

## 截图要求（TapTap 建议）
| 项目 | 规格 |
|------|------|
| 主截图 | 竖屏 1080×1920（9:16），至少 3 张，最多 8 张 |
| 封面图 | 1146×720 或 1280×720（横版封面，可选） |
| 格式 | JPG / PNG，单张 ≤ 5MB |

## 建议截取的游戏画面（覆盖核心玩法，便于过审与吸量）
1. **主界面（车位）**：展示车位、车辆、收取刀乐、每分钟收入——体现放置玩法。
2. **车库 / 图鉴**：展示 88 款车与 EDCBAS 评级色彩（白绿蓝紫橙红）。
3. **招募员工 / 员工加成**：展示员工位与收益加成。
4. **好友车位 / 贴条**：展示社交互动。
5. **欢乐夺宝 / 七日登录 / 名车之旅**：展示活动与任务系统。
6. **个人信息面板**：展示栽培我的老板、最有价值的车等。

## 如何截取（本地运行游戏）
- 方式 A：用 Android Studio 打开 `android-app/android` 工程，启动模拟器运行后截图。
- 方式 B：桌面浏览器直接打开 `index.html`（游戏为纯前端），按 375×812 移动视图截竖屏图，再缩放到 1080×1920。
- 截好的图放入本目录 `screenshots/` 文件夹，上传到 TapTap 后台「游戏截图」栏即可。
