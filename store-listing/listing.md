## 3. 详细介绍（商店长文案）
**《车行》** 是一款轻松治愈的放置经营小游戏。你是一家车行的老板，把各式各样的座驾停进车位，它们就会一刻不停地为你赚取「刀乐」。

**核心玩法**
- 🅿️ **放置收租**：车辆停在车位持续产出刀乐，满了点击「收取」即可落袋，离线也在赚。
- 🚗 **车型收集**：收录 88 款知名座驾，按 **E / D / C / B / A / S** 六级评级（白 / 绿 / 蓝 / 紫 / 橙 / 红），品质越高收益越可观。
- 👷 **招募员工**：雇佣员工安排到车上，获得收益加成，让收入更上一层楼。
- 🤝 **好友互动**：拜访好友的车行，在他们的专属车位「贴条」收费，也能把爱车停去好友家赚外快。
- 🎡 **欢乐夺宝 / 七日活动 / 名车之旅**：转盘抽奖、连续登录福利、章节任务，丰富的成长线等你解锁。
- 🏆 **车库图鉴**：已拥有的车一目了然，最有价值的座驾尽收眼底。

**游戏特色**
- 极简操作，竖屏单手即可游玩，随时随地收刀乐。
- 纯单机放置，不肝不氪，碎片时间轻松成长。
- 丰富的车辆图鉴与评级系统，收集党狂喜。

把车位停满，做最悠闲的车行老板！
