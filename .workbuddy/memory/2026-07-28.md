## 好友车位罚单：停留时间动态更新+30分钟门槛 (本地修改，未推送)

用户反馈（第6-7次修）：好友专属车位停留时间不动态变化；30分钟内仍可点开罚单。
### 根因
`updateParkGridsLite()` 中好友车位面板仅在**签名变化**时才调 `refreshFspotGrid()` 重建DOM。签名只包含 unlock/parkerUid/ticketed 三种结构性变化，不含时间——所以停留时间文本和按钮状态在两次结构变化之间完全冻结。

### 修复
新增 `_updateFspotTimes()` 函数（仿 `_updateParkNumbers` 模式）：
1. **每秒遍历所有 `.park-card[data-fspot]`**，找到停着车的好友
2. **动态计算 `parkedMins`**（基于 `parkedAtTs` 实时推算），更新 `.fspot-park-time` 文本
3. **动态切换按钮状态**：
   - 已贴单 → 灰色"已贴单" disabled
   - `parkedMins >= 30` → 绿色"开罚单"可点击
   - `parkedMins < 30` → 倒计时 disabled（如 "12:35"），数字每秒递减
4. **智能 DOM 替换**：仅按钮状态实际变化时才 `outerHTML` 替换，倒计时状态只改 `textContent`
5. `updateParkGridsLite()` 的 else 分支从空改为调用 `_updateFspotTimes()`

### 修改文件
- app.js: 新增 `_updateFspotTimes()` (~60行)；`updateParkGridsLite()` 加 else 分支

### 审核反馈

### 根因定位（非单纯设备适配，而是 JSBridge 注入时序 bug）
- **chexing-sdk.js 第33-34行**：`const isTapMiniGame = typeof tap !== 'undefined'; const isTapEnv = isNative || isTapMiniGame;` 是 IIFE 顶层**一次性 const**，脚本执行时求值一次。
- TapTap 小游戏的 `window.tap` JSBridge 是容器加载游戏后**异步注入**的，可能晚于游戏脚本执行。
- 在注入较晚的设备/时序下（一加5ace/荣耀400pro 旗舰机、最新 WebView 加载更快），脚本先跑、tap 后到 → `isTapMiniGame=false` 且**永不更新** → SDK 误判非 TapTap 环境。
- 连锁：boot() 第1253行 `(typeof tap !== 'undefined')` 同样误判 false → 不隐藏"跳过登录"；点登录 → tapLogin() `if(!isTapEnv)` 为真 → toast「请在 TapTap 客户端中使用登录功能」→ **永远进不去游戏** = 审核实测的"无法进入"。

### 修复（chexing-sdk.js + app.js，双份已同步 h5-build）
1. **chexing-sdk.js 环境检测改为动态**：
   - `isTapMiniGame` 由 const 改 `let`；删除 `const isTapEnv`，新增 `_isTapEnv()` 函数 + `refreshTapEnv()`
   - 新增 `_pollTapReady()`：每300ms 轮询（最多~10s）探测 `typeof tap`，注入后 `isTapMiniGame=true` 并触发已注册回调；`onTapReady(cb)` 导出
   - 导出 `isTapMiniGame/isTapEnv` 改为 **getter**（每次访问返回最新值）；`platform` 也改 getter
   - `tapCall` 的 `if(!isTapEnv)` 改为 `if(!_isTapEnv())`
2. **app.js boot() 改为动态 + onTapReady**：
   - 删一次性 `const isTapEnv`；新增 `initTapEnv()`（隐藏跳过登录 + 初始化SDK，只执行一次，用 `boot._tapReady` 标记）
   - 同步就绪 `if(isTapEnv) initTapEnv()`；异步就绪 `else if(onTapReady) onTapReady(()=>{ if(isTapEnv) initTapEnv() })`
3. **app.js tapLogin() 游客兜底（防审核卡死）**：
   - 登录失败/取消/异常分支 → toast 后 `setTimeout(enterGame, 900~1200)` 以**游客身份进入游戏**（enterGame 不依赖 S.taptap，兼容游客）
